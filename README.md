# 🕒 MiniProject Analogy Clock

A simple, interactive **real-time analog clock** built using HTML, CSS, and JavaScript.

The clock displays the current local time with hour, minute, and second hands.

## ✨ Features

- Real-time clock functionality
- Hour, minute, and second hands
- Clean and minimal user interface
- Responsive design
- Built with vanilla JavaScript

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and clock design
- **JavaScript** – Real-time clock functionality

## 📁 Project Structure

```text
MiniProject_Analogy_Clock/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/saurabh-tiwari-1/MiniProject_Analogy_Clock.git
   ```

2. Open the cloned folder in VS Code.
3. Open `index.html` using Live Server, or open it directly in your browser.

This project demonstrates how HTML, CSS, and JavaScript work together to create a real-time interactive web application.
